让文图在你的电脑上工作

完整应用需要 Node.js 24、Git 和你自己的模型 API。GitHub Pages 仅托管静态预览，不运行数据库或 AI 后端。

  1. 从 GitHub 下载或克隆 wentu 仓库。
  2. 按照 README 安装依赖、创建 .env 并初始化数据库。
  3. 运行 npm run dev，打开终端显示的 Local 地址。
  4. 在本地设置页配置自己的模型服务，确认能力与费用后开始制作。
